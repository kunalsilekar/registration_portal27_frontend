# Setup
1. Confirm GA4 measurement ID G-SYRV512144 belongs to your team. Replace REACT_APP_GA_MEASUREMENT_ID in frontend/.env.production if necessary. Rebuild/redeploy after changes.
2. Analytics Admin > Data streams > your web stream: turn OFF Enhanced measurement. This implementation sends manual public page views; automatic history/form tracking can duplicate events or collect sensitive URLs. Do not add another tag via GTM. Verify homepage and Modules in Realtime/Tag Assistant. Account pages and URL query strings are excluded from manual page views. No consent banner is implemented; connect your consent platform if required for your audience before enabling collection.
3. Search Console: add registrations.alcheringa.co.in as a Domain property, add Google's TXT record at your DNS provider, verify, and submit https://registrations.alcheringa.co.in/sitemap.xml. Inspect homepage and /modules and request indexing.
4. Check robots.txt and sitemap.xml on production. Link here from the main Alcheringa website. Configure alternate frontend domains to redirect to registrations.alcheringa.co.in on your VPS.

This React SPA still relies on JavaScript rendering for route metadata and noindex. Social previews use the shared initial HTML. Prerendering/SSR for public routes and real HTTP 404 responses are recommended next improvements; unknown routes currently receive client-side noindex with the SPA HTTP 200 fallback. Noindex is not access control. Dates and event offers were not invented for structured data. Analytics conversions should be added to successful API responses, not success-page visits.
